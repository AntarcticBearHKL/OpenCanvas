<h1 align="center">OpenCanvas</h1>

<p align="center">面向图片、视频与音频创作的开源画布工作台</p>

OpenCanvas 是一个纯前端的画布工作台，把画布编排、AI 图片 / 视频 / 音频 / 文本生成、图像与音频工作台、参考图编辑和素材沉淀放在同一个界面里，适合用来探索视觉方案并连续迭代结果。

## 核心功能

### 画布

- 多画布与库管理：新建 / 重命名 / 删除库与画布、跨库移动、左侧快速切换与拖拽排序。
- 节点拖拽与缩放、连线与关系标签、小地图、撤销重做、锁定 / 隐藏、对齐与等距分布、节点列表批量重命名。
- 顶部与左侧坐标标尺、16px 网格吸附、对齐参考线。
- 拖动图片 / 视频 / 音频等资源节点时显示跟随光标的小拖影，不再让整块节点挡住放置目标。
- 深色 / 浅色主题，点 / 线 / 空白三种画布背景。
- 整包导出 / 导入：把画布节点、连线、视图与全部图片 / 视频 / 音频资源打包成 ZIP，导入时新建画布、不覆盖已有数据。

### 工作区

顶栏可在三个工作区之间切换（路由 `/canvas/:id/:workspace?`）：

- 画布：默认的节点编排界面。
- 图像工作台（Image Studio）：Photoshop 式的图层合成工作区。
- 音频合成器（Audio Studio）：Cubase 式的多轨音频工作区。

两个工作室共用一套自研的可停靠面板系统：面板页签可在左 / 右 / 底三个停靠区之间拖动，拖动分隔条调整区域大小，「窗口」菜单开关面板，布局按工作区分别保存在浏览器本地。

### 节点（18 种内置）

- 内容节点：文本、图片、视频、音频。
- 提示词节点：图片提示词、音乐提示词、语音提示词、视频提示词。
- 生成节点：生成配置、图片生成、语音生成、音乐生成、视频生成。
- 画板节点：智能画布。
- 工具节点：资源、录音、图片修改器、音频合成器。

底部工具栏按「输入输出 / 提示词 / 修改器 / 生成器」四组创建节点，另有独立的「音频合成器」与「智能画布」按钮；提示词节点只负责提示词，通过连线接入生成节点。

### 图像工作台（Photoshop 式）

- 图层：图片 / 文字 / 形状 / 像素 / 调整 / 编组，支持排序、显示 / 隐藏、16 种混合模式与不透明度、图层蒙版。
- 非破坏性调整图层（亮度对比度、色阶、曲线、曝光、色相饱和度、渐变映射等）与图层样式（描边、投影、内 / 外发光、斜面和浮雕、颜色 / 渐变 / 图案叠加等），预览与「存为图片节点」导出共用一套栅格渲染器。
- 选区工具：矩形 / 椭圆选框、套索、多边形套索、魔棒、快速选择；配套通道面板与路径面板（钢笔、直接选择）。
- 绘制工具：画笔、橡皮擦、油漆桶、渐变、形状、吸管，以及颜色 / 渐变 / 图案 / 画笔素材面板。
- 滤镜菜单（模糊、锐化、杂色、像素化、风格化、扭曲等破坏性滤镜）与自由变换（斜切、扭曲、透视、网格变形、数值变换）。
- 图像菜单（图像大小 / 画布大小 / 旋转 / 裁剪到选区 / 修剪边框）、视图辅助（标尺 / 网格 / 参考线 / 吸附）、历史记录与动作面板。

### 音频合成器（Cubase 式）

- 多轨编排：音频 / 乐器 / MIDI / 编组 / 返送 / 主输出轨道；片段支持移动、非破坏裁剪、分割、复制、淡入淡出、循环、反相、增益、静音与锁定。
- 走带控制、节拍器、标记点、循环区域、穿插录音区间与网格吸附。
- 混音台：增益 / 声像 / 静音 / 独奏、立体声电平表、编组与返送总线、逐轨输出路由、前 / 后推子辅助发送。
- 参数自动化：音量 / 声像 / 发送增益可建自动化轨，线性 / 保持 / S 曲线插值。
- MIDI 与乐器轨：MIDI 片段按 PPQN 记录并跟随工程速度，内置合成器与钢琴卷帘编辑器。
- 录音：轨道待命、输入模式 / 声道 / 增益 / 延迟、预备拍，录制结果存为音频节点并落到轨道。
- 混音导出为音频节点，也可「导出分轨」把每条轨道单独渲染成音频节点。

### AI 生成

- 浏览器直连 OpenRouter（`https://openrouter.ai/api/v1`），API Key 存在本地，不经过任何项目服务器。
- 支持文本、图片（文生图与参考图编辑）、视频、语音、音乐。
- 图片：张数、分辨率（1K / 2K / 4K / 自动）、宽高比、质量、透明背景，保持原始比例。
- 视频：`minimax/hailuo-3-max`，480p / 768p、5-15 秒、六种宽高比；支持首尾帧与参考图（两者互斥），刷新页面后可继续轮询远端任务。
- 语音与音乐使用预设模型，输出 MP3。
- 生成结果直接排布在画布上，不会自动连线回生成节点；OpenRouter 返回用量时记录单次真实费用。

### 图片工具

- 裁剪、切图（本地 MobileSAM 点选分割）。
- 局部遮罩编辑：可只写入节点，也可立即生成。
- 分辨率：算法放大 / 算法缩小 / AI 提升。
- 抠图（本地背景移除模型，首次使用按需下载）。
- 图片分析：主色板、EXIF、感知哈希，并可按比例智能裁剪。
- 识别文字（OCR，走已配置的文本模型并生成文本节点）。
- 图片修改器节点：滤镜参数 + 色调参数（黑白场、gamma、曝光、高光、阴影）与可编辑色调曲线，可烘焙为新图片节点。
- 视频节点可截取首帧 / 尾帧 / 当前帧为图片节点。

### 智能画布

- 自包含的图层文档：图层、路径与通道都保存在画板节点自己的 `boardLayers` 等字段里，保存与导出随画板走。
- 在画布上渲染为一张只读信息卡片（比例 · 合成分辨率与图层数），图层本身只在图像工作台和合成导出中渲染。
- 固定比例画板，可选 1K / 2K / 4K 合成分辨率，支持背景色与背景不透明度。
- 把图片节点拖到画板上即按原始比例追加为图层，节点随后自动回弹到拖动前的位置。
- 图层面板：前后顺序、显示 / 隐藏、16 种混合模式与不透明度；画板内文字标注。
- 一键排版模板：网格 / 单行 / 单列 / 主图。
- 画板可嵌套，递归渲染与递归合成。
- 双击预览合成结果，或一键存为图片节点。

### 资源与浏览器扩展

- 「资源」节点绑定本地文件夹（File System Access API），每个节点各自绑定、按节点保存在本地；列表内可进入子目录与返回上级，范围以绑定的根目录为界。
- 以文件名列表展示图片 / 视频 / 音频 / 文本，悬停可按需预览单个文件，拖出即插入画布。
- 把图片节点拖到资源节点上，会把图片写入该节点绑定的文件夹。
- 可选浏览器扩展（`extension/`，Chrome / Edge MV3）：在任意网页右键图片「添加到 OpenCanvas 缓存」，资源节点可切换到「插件缓存」来源并直接拖入画布。

### 本地画布 MCP

- 前端服务在同一端口 3000 同时提供网页与 HTTP MCP：`http://127.0.0.1:3000/mcp`，共 30 个画布工具。
- 网页同源自动连接，不需要 token，也不需要配置文件。
- 可读取当前画布与选区、创建与编辑内置节点、连线、触发生成、整理智能画布与图层。
- 设置 → Agent 可逐类开关画布操作权限，并保留操作审计日志与回放。
- 没有内置聊天助手：由外部 MCP 客户端（例如 opencode）通过后台桥接驱动画布。

### 插件系统

- 通过 URL 安装 / 启用 / 更新 / 卸载远程节点插件，内置官方插件注册表。
- 提供 TypeScript SDK，可开发带面板、资源输入与可选 AI 生成的画布节点插件。

## 快速开始

```bash
git clone https://github.com/AntarcticBearHKL/OpenCanvas.git
cd OpenCanvas/web
bun install
bun run dev
```

运行后默认端口 3000，访问 `http://localhost:3000`。

## 配置

- 打开右上角设置 → 接口，填入 OpenRouter 的 API Key。
- API Key、画布项目与生成记录都保存在浏览器本地，由前端直接请求 `https://openrouter.ai/api/v1`。

## 浏览器扩展（可选）

```
chrome://extensions → 打开「开发者模式」→「加载已解压的扩展程序」→ 选择本仓库的 extension/ 目录
```

安装后在任意网页右键图片即可加入缓存，随后在画布「资源」节点切换到「插件缓存」来源使用。详见 [`extension/README.md`](extension/README.md)。
