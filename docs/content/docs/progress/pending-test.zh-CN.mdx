## 提供商、写死模型与 Matilda

- 现在只提供三个提供商：OpenRouter、DeepSeek 与 Matilda（Maincode）。每个渠道的模型列表来自预设 —— OpenRouter 承载多模态那套（图片 `openai/gpt-image-2.5-sunburst`、视频 `minimax/hailuo-3-max` / `minimax/hailuo-3`、语音 `fish-audio/s2.1-pro`、音乐 `google/lyria-3-pro-preview`，以及 5 个文本 id），DeepSeek 承载 `deepseek-v4-pro` / `deepseek-v4-flash`。
- 「抓取模型」功能已移除：不再调 `GET {base}/models`，也没有每个提供商的抓取按钮。删掉它是对的 —— 实时 OpenRouter 目录（458 个模型）里根本没有本应用的图片 / 视频 / 语音 id，抓回来的列表反而不可用。
- DeepSeek 与 Matilda 是纯文本提供商：它们的模型一律归类为 `text`，能力控件对它们只读，也永远不会出现在图片 / 视频 / 音频 / 语音的下拉里。其它提供商的既有渠道不受影响，只有能匹配到预设的渠道会被重置模型列表。
- Matilda 通过本地同源代理运行（`web/matilda-proxy.ts`，已在 `vite.config.ts` 里为 dev 与 preview 注册）。代理在 Node 侧驱动官方 `@maincode-ai/matilda-agent-sdk`，并把它重新暴露为 OpenAI 形状的 `/matilda/v1/responses`、`/matilda/v1/chat/completions` 与 `/matilda/v1/models`，所以你只需要在 Matilda 渠道里粘贴 `mc_live_...` 密钥，不用管模型 id 和能力分类。
- 需要你确认的几点：(a) Matilda 的正常链路**没有用真实密钥测过**（这台机器上没有密钥 —— SSE 翻译是用 mock 重放 SDK 的真实事件名校验的，线上只探到它的 401 行为）；(b) 如果 Matilda 渠道已经存成了旧的绝对地址 `https://matilda.maincode.com/api/v1`，请重新选一次「Matilda (Maincode)」预设（或删掉该渠道）；(c) `npm run dev` 能用代理，但 `npm run start` 用的是旧的 `dist`，静态生产部署需要等价的 Node 函数；(d) 只带图片的 Matilda 请求会返回明确的 400，而不是编一个答案。

## 画布节点与编辑

- 节点名称始终显示在卡片上方，没有单节点名称开关；悬停工具栏的「显示标签」开关控制所有节点类型悬停工具栏按钮的文字标签，并在刷新后保留状态。
- 节点卡片默认没有描边，只有选中、关联节点和拖放目标状态会显示轮廓。
- 节点列表与悬停工具栏可以锁定或隐藏节点：锁定后节点不能拖动、缩放、编辑、删除，也不会被框选拿走，但仍可选中以便解锁；隐藏后节点不渲染、不能被点击或作为连线目标，可从节点列表恢复；每次锁定、隐藏或重命名都能用一次撤销还原。
- 底部工具栏的「节点列表」（以及悬停工具栏的「层级」弹层）可打开节点面板，按类型筛选、对多选行批量重命名（单选保留原名，多选追加编号），并逐行切换锁定/隐藏。
- 拖动节点会吸附到 16px 画布网格，但当某条边或中心与另一节点相距 6 个屏幕像素以内时优先使用对齐参考线；任意缩放下松开后的落点都与拖动预览一致。

- 第五阶段补齐 MIDI 与乐器轨：轨道新增「乐器 / MIDI」类型（各自自带合成器，乐器轨可从预设列表选择音色）；MIDI 片段以 PPQN 刻度（每四分音符 960 ticks）记录、跟随工程速度，可在编曲区像片段一样移动、两端裁剪、分割、复制与删除。双击片段（或切到中间视图新增的「钢琴卷帘」）会为该片段打开基础钢琴卷帘编辑器：双击空白处画音符、拖动音符移动、拖右边缘改长度、在下方力度区拖动改力度、双击音符或按 Delete 删除、方向键微调（Shift 按小节 / 八度）。合成器与音频片段一样接入同一条通道条，推子、声像、静音、独奏、发送与输出路由全部生效；播放与离线混音导出仍共用同一个音频图构建器，因此导出的 WAV 同样包含 MIDI 轨。
- 第六阶段补齐录音与导出完善。走带上的录音按钮（位置读数左侧的圆点，以及窄屏「…」菜单里的同一按钮）从「切换录音待命」改为真正录音：先让一条音频轨道进入录音待命，点击它会在这同一个手势里解锁音频上下文并打开浏览器默认输入，按工程设置里选定的预备拍（0 / 1 / 2 / 4 小节，预备拍在音频时钟上先于走带播放、每小节首拍重音，因此不会占用或整体偏移录制内容）倒数，然后让走带从播放头起跑（穿插录音只从这段采集中裁出穿插范围，其余部分丢弃）；再次点击该按钮，或按空格 / 暂停 / 停止都会结束这次录音，穿插录音到达出点、普通录音到达工程结尾也会自动收尾。按钮显示的是录音状态（录音中为 `activeBg` 加阻塞色）而不再是待命状态——待命开关仍在轨道表头、混音台通道条与检查器上，没有任何轨道待命时点击录音会给出提示而不是静默无反应。工程设置新增「录音输入」区（在穿插录音与节拍器之间）：录音模式（普通从播放头录，穿插只在已启用的穿插范围内录并在出点停下）、预备拍、声道（单声道会把输入下混）、输入增益与输入延迟（成片整体前移该毫秒数以对齐迟到的输入）。录音期间输入经该轨道自己的通道条监听，推子、声像、静音与独奏全部生效。结束一次录音会先解码、裁掉预备拍前置部分、按声道设置下混，再以 16 位 WAV 上传；随后一笔编辑同时把新的音频节点放到画布上（工程节点旁）并把片段放到待命轨道上，覆盖范围内的原有片段按新录音裁剪（被覆盖片段裁到成片边界、中间被覆盖的部分删除）——因此反复录制就是多条 take，一次录音只产生一次撤销，音频字节始终不进入文档。节拍器改为真正发声：每拍一次点击、小节首拍重音，音量沿用工程设置，速度与拍号变化即时跟随，播放与录音时出声，但刻意不进入离线混音导出，所以导出的 WAV 里不会有节拍声。导出侧同样补齐：「存为音频节点」在导出期间显示「导出中…」并禁用，「轨道」菜单新增「导出分轨」，对每条轨道用同一个共享音频图构建器离线渲染一条分轨（音频 / 乐器 / MIDI 轨渲染自身内容，分组轨精确汇总路由进它的轨道），并在一次编辑里为每条分轨生成一个音频节点。以下刻意未实现：循环录音（每圈一条 take）、返回轨分轨（其湿信号无法与发送方的干信号分离）、主输出分轨（它就是混音导出）。
- 在画布上把「音频」节点拖到「音频合成器」节点上即可把该音频加入工程：拖动时音频合成器节点会高亮为放置目标，松开后每个被拖入的节点都会新建一条以节点标题命名的轨道（标题为空时回退为工作台既有的「轨道 N」命名），并在该轨道上追加一个引用该节点的片段，片段起点按工作台「下一个片段位置」计算、时长用工作台自己的时长探测（读不到时长的节点回退为 5 秒）；被拖动的节点会动画回弹到拖动前的位置并保持普通可拖拽节点，整次多节点拖放只产生一次撤销。
- 音频工作台补充修复：轨道行高按表头内容固定为 68px，表头列与片段行逐行对齐、互不遮挡（「添加轨道」行与主输出行也包含在内），轨道行始终正常绘制片段、MIDI 片段与波形。表头第二行改为固定列槽位，静音、独奏、录音待命指示与增益输入在音频 / 乐器 / MIDI / 分组 / 返回 / 主输出以及增益自动化行上都停在同一列：某行缺少待命指示或自动化链接图标时保留该列占位而不是挤动后面的控件，窄屏下静音 / 独奏 / 指示槽位同步收窄，控制行不会溢出表头。推子范围改为 -60 dB … +6 dB——底部表示静音、0.0 dB 为单位增益——因此轨道、发送与主输出既可以衰减也可以提升；表头、检查器、混音台与增益自动化轨共用同一范围，正向数值显示为「+3.0 dB」。拖动片段（移动 / 裁剪 / 淡入淡出 / 循环）、MIDI 片段、自动化断点与框选时只在被拖动元素上预览、松手时一次性写入文档，拖动不再每帧重渲染整个工作台，且一次拖动仍然只产生一次撤销。未命名的主输出 / 分组 / 返回轨按角色显示（如「主输出」）而不再被编号成轨道，新建工程不会再出现「Master Track 2」。走带行与选项栏的控制统一为同一高度 28px：速度输入、拍号、循环 / 节拍器按钮、选项栏菜单与「窗口」按钮、网格 / 吸附 / 自动交叉淡化开关、吸附与淡入形状下拉在高度、圆角、边框颜色与左右内边距上完全一致，拍号下拉的箭头回到框内而不是叠在内容下方（此前它因此整框高达 36px，比旁边的速度输入更高）。两行高度保持 44px 与 36px 不变，选项栏的控件改为可收缩并换行，选中片段（出现淡入形状 / 片段增益 / 循环 / 反转）且窗口较窄时不再被裁切。
- 音量不再用滑杆：除了混音台通道条自己的竖直推子与电平表，工作台里其余的增益一律改成紧凑的数值输入框（轨道表头、检查器、发送增益、片段增益、录音输入增益、节拍器音量与工程总音量）。显示格式与原推子一致（静音显示「-∞ dB」、单位增益「0.0 dB」、正向「+3.0 dB」），输入过程中可以正常输入 -、+ 与小数点，按回车或失焦才提交，自动夹到与该推子相同的范围并只写一次文档（双击输入框恢复该参数的默认值）。标尺与播放头可以按住拖动来连续改变播放位置：在标尺整个高度上按下（含播放头）左右拖动即可刷新播放时间，播放中保持播放并跟随指针，位置只写到传输时钟与播放头元素上（不写文档，因此拖动不会逐帧重渲染工作台），单击标尺仍然一步跳转；标尺显示左右拖动光标、悬停底色与提示文字。
- 底部工具栏在画布区域内居中，窄屏下横向滚动。从左到右依次是：导出画布；选择/平移切换；撤销；重做；输入/输出菜单（资源、录音、音频合成器）；提示词菜单（提示词、音乐提示词、语音提示词、视频提示词）；修饰菜单（图片修饰）；生成器菜单（图片生成、音乐生成、语音生成、视频生成）；分割线；智能画布；按需出现的扩展菜单；缩放弹层；节点列表按钮；以及有节点选中时才出现的删除。「视频」媒体节点不再出现在这里。面板打开时不再显示按钮提示。
- 「缩放」工具的弹层提供 5%-500% 滑杆与实时百分比、「重置视图」、小地图开关（开启时高亮）和「快捷键」入口；点击外部或按 Esc 关闭，拖动滑杆时保持打开。
- 坐标标尺渲染在顶栏下方并组成 L 形（上边和左边），随平移、缩放实时更新，缩小到一定程度自动拉大刻度间距，且只作展示、不拦截点击或拖动；每张画布在切换和刷新后都会记住自己的缩放与镜头位置。
- 提示词库体系已整体移除：没有 `/prompts` 页面和顶部导航入口，没有「设置 → 提示词来源」页签，画布提示词面板没有「从预设库选择」入口，MCP 也不再提供 `prompts_search` 工具（剩余 30 个画布工具）。提示词节点仍保留编辑面板、预设标签按钮和引用芯片。

- 参考图挂在提示词节点上；每条「参考图 N」连线都有标签，提示词节点为每个参考图显示可拖动的名字芯片，拖进编辑器即在当前光标处插入对应提及。
- 所有节点面板顶部的参考条已移除：任何节点都不再显示参考缩略图、「添加参考」按钮或逐条断开入口。参考图仍通过节点连线传入生成；提示词节点的可拖动参考芯片保持不变。

- 大纲节点的「AI 展开下级」按下一层级要 3-6 个子节点（卷→章→场景→节拍、幕→场→镜头），带摘要创建；模型返回无法解析时不创建任何节点并提示失败。

## 生成

- 同时发起多次生成时，所有请求统一经一个并发上限为 2 的共享队列执行，排队中的图片仍显示为等待中，而不是一次性全部打到接口。
- 生成失败会自动重试最多 3 次、每次间隔 2 秒，之后才报告失败。
- 生成的图片、视频、音频和文本结果直接排布在画布上，不会自动连回生成节点；只保留用户手动创建的连线。
- 生成中的图片变为成功时会播放一次轻微的放大 + 上浮 + 淡入入场动画（约 0.42s）；已在画布上的图片不会重复播放，系统开启「减少动态效果」时会关闭。
- 生成完成后，图片节点信息条显示从 OpenRouter 响应读取的真实费用（`usage.cost`）并标注来自真实返回；响应没有费用时显示本地估算值并标注为估算。
- 视频生成节点（或视频模式的生成配置节点）选择 `minimax/hailuo-3-max`（480p/768p、无音频、默认）或 `minimax/hailuo-3`（2K、原生音频）时使用 OpenRouter 原生异步视频接口：请求体携带 model、prompt、duration、resolution、aspect_ratio，以及首尾帧模式的 `frame_images` 或参考模式的 `input_references`（两者不会同时发送，模式与槽位绑定读取自连接的「视频提示词」节点）；每个首尾帧条目都带显式 `frame_type`，只绑尾帧时不会被当成首帧发送；参考素材条目按媒体类型使用对应的 `image_url` / `video_url` / `audio_url`，只有模型支持音频时才发送 `generate_audio`。视频生成节点内联展示模型、模型自身的清晰度（只有一个时显示整行 2K 药丸）、5-15 秒、六种宽高比（1:1 / 3:4 / 4:3 / 16:9 / 9:16 / 21:9）与音频开关，没有 W/H 输入框与设置弹层，不发送 `size` / `watermark` / `seed`；本地视频与音频参考会从浏览器存储读出真实字节并转成 base64 data URL，视频超过 50MB、音频超过 15MB 或编码后合计超过 64MB 时会明确报错；其他视频模型（渠道模型与插件脚本）的面板与请求路径保持不变。
- 只接受一张关键帧的视频模型（`minimax/hailuo-3` 与 `minimax/hailuo-3-max`）在「视频提示词」节点的首尾帧模式下只显示一个「关键帧」槽位，并可用「首帧 / 尾帧」切换改变它对应到哪一种帧：切换会把已绑定的图片改挂到新的帧类型，不会同时保留两张帧，下方提示该模型只接受一张关键帧；请求发送前会按模型上限截断 `frame_images`，因此旧画布即使同时保存了首帧和尾帧也不会再报错。能力允许两张帧的模型仍保留原来的双槽位布局。

## 智能画布

- 「智能画布」是固定比例、可选 1K/2K/4K 合成分辨率的画板（默认 16:9 / 2K），支持背景颜色（透明 / 白 / 黑 / 自定义）与背景不透明度；切换比例会按比例缩放画板。
- 画板是自包含的图层文档：图层（图片层 / 文字层）连同位置、尺寸、旋转、不透明度、混合模式与显隐都保存在画板节点自己的 `boardLayers` 里，坐标是画板本地坐标（数组顺序即层级，索引 0 在最底层），不再依赖画布节点的位置或 `metadata.boardId`。
- 把图片节点或画板节点拖到画板上会为每个节点追加一个图片图层（按原始比例居中适配画板、名字取节点标题），随后节点动画回弹到拖动前的位置；节点仍是普通可拖拽节点，不会留在画板上。拖动时画板作为拖放目标高亮。
- 画板节点在画布上是纯信息卡片（结构与音频合成器卡片一致）：显示画板图标、比例 · 分辨率一行与图层数，节点标题仍显示在卡片上方；不再渲染画板的背景、网格、图片层、文字层与嵌套画板，因此改动文档内部不会再重绘画布卡片，图层文档只在图像工作台与合成 / 导出路径中渲染。
- 画板面板缩减为画板设置（比例 / 分辨率 / 背景 / 不透明度）与「存为图片节点」；双击画板打开合成预览，悬停工具栏的「存为图片节点」会按需合成（递归嵌套画板，并按图层顺序与各层的混合模式、不透明度、旋转绘制）并在右侧生成图片节点。
- 图层顺序、显隐、混合模式、不透明度与旋转同时作用于画布预览与合成导出：预览用 CSS `mix-blend-mode` / `rotate`，导出用 canvas 的 `globalCompositeOperation` 与中心旋转；文本层按字号、颜色与多行内容绘制。
- 把画板拖到另一个画板上会成为它的图片图层（嵌套画板递归渲染、按各自矩形裁剪），画板不能拖入自身或子孙；数据里若已有循环，预览与合成都直接跳过而不是死循环。
- 图像工作台工作区是围绕当前画板自身图层文档的 Photoshop 式图层编辑器：顶部第一行是画板栏（画板切换、比例 / 分辨率 / 背景 / 不透明度设置、缩放读数、适应窗口、「存为图片节点」），第二行是选项栏，从左到右依次是「选择 / 图像 / 视图」三个菜单与当前工具自己的选项（画笔 / 橡皮擦的大小、硬度与不透明度，油漆桶与魔棒的容差，选框的羽化与消除锯齿，渐变的类型、混合模式、不透明度、色标位置、反向与两个色板，形状的类型、填充、描边与描边宽度，以及前景色色板），左侧工具栏（移动、抓手、矩形选框、椭圆选框、套索、多边形套索、魔棒、快速选择、画笔、橡皮擦、油漆桶、渐变、形状、吸管、放大 / 缩小）、中间文档视图，以及围绕视图的可停靠面板：左侧「属性 / 调整」，右侧「图层 / 通道 / 路径 / 历史记录 / 动作」，底部素材面板；所有面板都在选项栏的「窗口」菜单里列出，可拖动页签在停靠区之间移动、拖动分隔条调整大小，布局按工作台记录并在刷新后保留。
- 视图支持拖拽空白处或按住空格平移、滚轮以光标为中心缩放（5%-800%）与适应窗口；文档按与画板预览完全相同的图层框架、混合模式、不透明度与旋转渲染背景与图层，并裁剪到文档边界。选中图层会显示 Photoshop 式选区框与四个角缩放柄、一个旋转柄（按住 Shift 按 15 度吸附），拖动图层主体可移动，锁定图层不可变换，隐藏图层不参与渲染，双击文字层可在文档上直接改字。「视图」菜单可开关标尺（顶部与左侧，刻度随平移缩放更新；从标尺向文档内拖动可创建水平或垂直参考线，参考线按画板记忆、本次会话内有效）、覆盖在视口上的文档网格、参考线本身与对齐：移动或缩放图层时，图层的边缘与中心会吸附到参考线、文档边缘与中心、以及其他图层的边缘与中心（6 屏幕像素内，显示彩色对齐线，开启时选项栏显示磁铁提示）；参考线可以再次拖动，拖出文档范围即删除，「清除参考线」一次清空。
- 图层文档新增像素图层：选中像素图层后，用画笔或橡皮擦在文档上按住拖动即可连续绘制（大小、硬度与不透明度来自选项栏，笔刷圆环跟随光标并随缩放变化），橡皮擦按 destination-out 擦除且只作用于自己的图层，油漆桶按容差做 4 邻域填充，吸管从合成结果中取光标处的颜色并写入前景色。当前图层不是像素图层（未选中或选中的是文字 / 图片 / 组图层）时，第一次绘制会自动新建一个覆盖整个画板的像素图层并选中它，选项栏同时给出提示。一次拖动（或一次油漆桶点击）只在松开时写回一次 `boardLayers`，所以一次撤销即可还原整笔；图层自己的位置、旋转、不透明度与混合模式照常生效，画板预览与「存为图片节点」导出的结果一致。像素图层的位图通过图片存储以 `storageKey` 保存（不会塞进节点 metadata），因此画布文件体积不受影响，并且会被图片清理扫描当作在用资源保留。
- 选区是一张与文档同尺寸的蒙版画布（alpha 即选中范围），只存在于编辑器状态、不会写进画板文档：矩形选框、椭圆选框、自由套索、多边形套索（依次点击加点，回到起点或按回车闭合，Esc 取消）、魔棒（可设容差、是否连续，以及取样全部图层或当前像素 / 图片图层）与快速选择（在合成结果上按住拖动沿相近颜色扩展，Alt 拖动收缩）都能创建选区，按 Shift 加选、按 Alt 减选。选区边界显示为动态虚线（marching ants，手势进行中隐藏），「选择」菜单提供全选 / 取消选择 / 反选 / 羽化（对应 Ctrl+A、Ctrl+D、Ctrl+Shift+I）；切换工具后选区保留，取消选择以及文档发生变化（切换画板、切换比例、图像大小、画布大小、旋转、裁剪、修剪）时清空。画笔、橡皮擦、油漆桶与渐变的每一次绘制都会被选区裁剪，存在选区时新建的形状会自动带上由该选区生成的图层蒙版。
- 图层可添加可选蒙版（`maskStorageKey`，同样是图片存储里 `image:` 前缀的位图，白色显示、黑色隐藏）：「图层」面板在图层缩略图右侧显示蒙版缩略图，并用高亮圈标出当前编辑的是图层还是蒙版，Alt 点击蒙版缩略图会在文档中查看蒙版本身；「属性」面板提供添加蒙版（按当前选区生成，没有选区时生成全白蒙版）/ 删除蒙版 / 应用蒙版（把蒙版烘焙进位图，仅像素图层可用）。把蒙版设为编辑目标后，画笔、橡皮擦、油漆桶与渐变改为编辑蒙版本身——前景色偏暗即隐藏、偏亮即显示，橡皮擦恢复显示——画布预览用 CSS `mask-image`、合成导出用 canvas 的 `destination-in`，两条路径都先用图层自身内容乘以蒙版，再应用图层的不透明度与混合模式。
- 渐变工具支持线性 / 径向、两个色标 + 色标位置、混合模式、不透明度与反向，在文档上拖出方向与长度后写入当前像素图层（或蒙版），同样被选区裁剪；形状工具可拖出矩形 / 圆角矩形 / 椭圆 / 多边形 / 直线（按住 Shift 约束比例，圆角半径与多边形边数在「属性」面板调整，填充 / 描边 / 描边宽度在选项栏与「属性」面板编辑），形状是新的 `shape` 图层类型，可以像其他图层一样移动 / 缩放 / 旋转；预览用内联 SVG 绘制，导出用同一份路径数据通过 `Path2D` 绘制。
- 「图像」菜单提供图像大小（重采样整个文档：所有图层几何与像素 / 蒙版位图一起缩放）、画布大小（只改文档框、不缩放内容，可选九宫格定位）、图像旋转（顺时针 / 逆时针 90°、180° 与任意角度，任意角度按旋转后的包围盒扩展画布）、裁剪到选区与修剪边框（按可见图层包围盒去掉空白边）。所有操作都写回 `boardLayers`，文档尺寸变化会让画布上的画板节点一起改变大小，并把 `boardRatio` 更新为最接近的预设比例。
- 「图层」面板按从上到下的层级列出图层（图片层显示解析后的位图缩略图、像素层显示自己的位图缩略图、有蒙版的图层在缩略图旁显示蒙版缩略图并圈出当前编辑目标、文字层显示 T 字形图标、组显示文件夹图标、形状层显示形状图标），每行有显示（眼睛）与锁定开关，双击名称可改名；面板标题行提供添加图片层（从画布图片节点中选择）、添加文字层、编组、取消编组、复制、删除、上移、下移，并显示当前图层的混合模式与不透明度。图层行既可按拖动排序（拖到组上会放进组内），也可用上移 / 下移调整。
- 工具快捷键：V 移动、H 抓手（空格仍为临时抓手）、M / Shift+M 矩形选框与椭圆选框、L / Shift+L 套索与多边形套索、W 魔棒、A 快速选择、B 画笔、E 橡皮擦、G 油漆桶、Shift+G 渐变、U 形状、I 吸管，Ctrl+A / Ctrl+D / Ctrl+Shift+I 全选 / 取消选择 / 反选，[ / ] 调整笔刷大小。
- 组是单层级的容器，拥有自己的名称、不透明度、混合模式、显隐与锁定；组内图层先在隔离环境中合成，再整体应用组的不透明度与混合模式，画布预览与导出 PNG 的行为一致。
- 「属性」面板可编辑选中图层的名称、位置、尺寸、旋转（图片层与文字层）、不透明度与混合模式，新增蒙版行（添加 / 删除 / 应用），形状层可编辑形状参数（形状类型、填充、描边、描边宽度、圆角半径、边数），文字层还可编辑文字内容、字号与颜色。所有改动都通过画布状态写回画板节点自己的 `boardLayers`，因此撤销 / 重做、自动保存、刷新持久化与「存为图片节点」导出都照旧可用。
- 调整图层是新的 `adjustment` 图层类型（数组顺序仍是 z-order），提供 15 种非破坏性调整：亮度/对比度、色阶、曲线（可拖动控制点的曲线编辑器）、曝光、自然饱和度、色相/饱和度、色彩平衡、黑白、照片滤镜、通道混合器、渐变映射（可增删色标）、反相、色调分离、阈值与可选颜色。调整图层只影响同一容器（文档层或所在组）中它下方的图层（Photoshop 语义），自身可设不透明度、混合模式、显隐、名称与蒙版，参数逐像素通过 `ImageData` 计算（能用查找表的走 256 级 LUT）。图层面板下方的「调整」面板与图层面板底部的「调整图层」菜单都能新建，选中调整图层时点面板里的类型会替换它的类型并重置为该类型的默认参数。调整图层没有自己的像素，因此不参与修剪边框的包围盒，也不会挡住画布上其他图层的点选；「属性」面板会为选中的调整图层显示对应参数控件。
- 「滤镜」菜单按分组列出 22 个破坏性滤镜——模糊（高斯模糊、方框模糊、动感模糊、径向模糊、倾斜模糊、光圈模糊）、锐化（锐化、USM 锐化）、杂色（添加杂色、去斑、蒙尘与划痕）、像素化（马赛克、晶格化）、风格化（浮雕、查找边缘、曝光过度、云彩、镜头光晕）与扭曲（波纹、挤压、球面化、液化）。每个滤镜都有参数对话框与实时预览（预览在缩小副本上计算）；确认后重写目标图层的位图（文字、形状、图片与组图层会先栅格化为像素图层，对话框中有提示），只写一次 `boardLayers`，所以一次撤销即可还原，并按图层蒙版与当前选区裁剪结果（未覆盖处保留原像素）。「重复上一次滤镜」按上次参数直接再应用一次；液化是交互式的（在预览上拖动推移像素，重置可重来，参数为画笔大小与压力），不会记入「重复上一次滤镜」。
- 图层样式（fx）适用于除调整图层外的所有图层，包含描边、投影、内阴影、外发光、内发光、斜面和浮雕、光泽、颜色叠加、渐变叠加与图案叠加，每种都有 Photoshop 的主要参数（大小、位置、颜色、角度、距离、扩展、深度、柔化、高光 / 阴影颜色与不透明度、缩放、不透明度与混合模式；渐变叠加可编辑色标，图案叠加使用内置棋盘 / 圆点 / 条纹 / 交叉线图案）。投影与外发光绘制在图层内容下方，其余样式绘制在内容上方（与 Photoshop 一致）。「图层」面板底部有「图层样式」入口，双击任意图层行也会打开同一面板，每种样式都有启用勾选框与参数控件。
- 预览与导出改为共用一个栅格渲染器：`renderPsDocument`（画板文档 → canvas）同时用于「存为图片节点」导出、节点生成合成、吸管 / 魔棒取样与图像工作台的文档画面，因此调整图层与图层样式只有一份实现，预览与导出在结构上一致。没有调整图层、也没有启用图层样式的文档仍走原有 DOM 渲染路径（实时绘制、混合模式与蒙版不变）；一旦出现调整图层或已启用样式，编辑器就切换到栅格路径，并按内容签名复用，输入不变不会重复重绘。
- 图像工作台的面板改为可停靠系统：所有面板（图层、通道、路径、历史记录、动作、调整、属性与素材面板）只声明一次，由选项栏的「窗口」菜单统一显示、隐藏与移动；拖动面板页签可停靠到左 / 右 / 底任意一边（同一停靠区里的多个面板以页签堆叠），拖动分隔条可调整停靠区大小，布局按工作台保存，原来的固定右侧面板栏已被替换。素材面板包括：真正的 Photoshop 式取色器（饱和度 / 明度方块、色相条、HSB / RGB / 十六进制输入、前景 / 背景色块并支持交换与恢复黑白色）作为编辑器的取色来源；色板网格可把当前前景色加入色板、右键删除任一色板；渐变面板的色带可拖动色标编辑（每个色标有颜色、位置与中点），并可命名、保存与删除；图案面板可从当前选区或当前图层定义图案；画笔面板中每个预设都用与画笔工具相同的笔尖绘制实时预览笔迹，并可编辑大小、硬度、不透明度、间距、散布、角度、圆度、动态与纹理，还能保存、重命名与删除。预设属于用户数据，通过基于 localforage 的 `use-ps-asset-store` 持久化（不使用 localStorage）；图案位图写入图片存储并使用 `image:` 前缀，图片清理会一并读取图案列表，因此已保存的图案位图不会被当作未使用资源清除。
- 「自由变换」在原有移动 / 缩放 / 旋转之上新增斜切、扭曲、透视与变形：从新的「编辑」菜单进入变换（Ctrl+T 为普通变换框），图层的变换手柄会换成对应模式的手柄——斜切为八个边 / 角手柄，扭曲为四个角，透视为对角联动，变形为可拖动的 4×4 控制网格。变换以归一化的四边形或 4×4 网格保存在图层自身的 `transform` 上，所以移动、缩放、旋转、编组与蒙版仍然可用，共享栅格渲染器把网格细分为仿射三角片来绘制（仿射网格只用一次裁剪变换），因此预览与导出在结构上一致。「编辑」菜单还提供「数值变换…」（水平 / 垂直移动、水平 / 垂直缩放、旋转、水平 / 垂直斜切）、「重复上一次变换」（Ctrl+Shift+T）与「清除变换」；每次变换是一次撤销，形状与文字图层同样支持这些变换。
- 文字图层新增了「字符」与「段落」面板所需的字段，选中文字图层时显示在「属性」下方：字体、字号、颜色、仿粗体 / 仿斜体、下划线与删除线开关、字距调整、字偶间距、行距、基线偏移、水平与垂直缩放，以及正常 / 全大写 / 全小写 / 小型大写；段落部分提供对齐（左、居中、右、两端对齐）、左 / 右 / 首行缩进、段前距、段后距与连字开关。这些全部由共享栅格渲染器逐字排布与绘制（字距、字偶间距、缩放与装饰线与导出一致），还包括沿路径文字（文字图层可跟随任意已保存路径，字形按弧长沿路径排布并旋转）与文字变形（弧形、下弧、上弧、旗帜、波浪、鱼形、上升、凸起、贝壳、挤压，带弯曲与水平 / 垂直扭曲），文字变形与图层变换走同一套网格绘制。
- 「通道」面板显示文档的 RGB 复合通道与红、绿、蓝三个通道：点击某个通道会在视口中以灰度显示该通道（合成结果仍来自共享渲染器，只是把该通道复制到三通道），每个通道都有眼睛图标，隐藏后复合结果在预览与导出中都会去掉该通道。当前选区可以存储为具名 Alpha 通道，并可载入为选区、就地重命名与删除；Alpha 通道属于文档数据，保存在画板节点自身的元数据里，位图使用 `image:` 前缀并随画板一起保存、刷新与导出。
- 「路径」面板为画板文档加入矢量路径：钢笔工具单击放置锚点、拖动拉出对称控制柄形成曲线，单击起点闭合、Esc 结束；直接选择工具可移动锚点与两个控制柄；面板列出每条路径（含 SVG 缩略图、眼睛、就地重命名、新建 / 复制 / 删除）并提供「建立选区」「填充路径」「描边路径」以及颜色色块。路径保存在画板元数据中，其几何通过同一个折线化辅助函数与渲染器共享，因此沿路径文字与填充路径使用的是同一形状。
- 「历史记录」面板是文档状态的可点击列表：每次提交 `boardLayers` 都会按操作名推入一条记录，点击某条记录即可回到该状态，左右箭头逐个后退 / 前进，「快照」把当前状态固定一份副本，列表上限为 50 条（面板标题中有说明）。历史记录只是编辑器状态：仅存在于本次会话的内存中，绝不写入画板或项目文件，面板中也有说明。
- 「动作」面板录制编辑器自身的文档命令：点击「录制」开始捕获，录制的内容包括菜单命令（选区操作、裁剪、修剪、三种旋转）、图层命令（复制、删除、上移 / 下移、编组、取消编组、栅格化）、新增调整图层、带参数的滤镜应用与数值变换；「停止」结束捕获，可命名并保存步骤列表，随后按需播放、重命名与删除。手绘笔迹明确不可录制，面板中也有说明。动作属于用户数据，与预设使用同一个基于 localforage 的 store 持久化。
- 工具栏新增钢笔与直接选择工具（P / Shift+P）；在原有的选择 / 图像 / 滤镜 / 视图菜单之外新增「编辑」菜单，提供自由变换、数值变换、重复上一次变换与清除变换；选项栏跟随工具变化：钢笔与直接选择显示当前路径并允许清除当前图案，油漆桶同样显示当前图案，进入变换模式后显示模式切换与「完成」按钮。

## 图片工具

- 图片节点悬停工具栏显示已启用的快捷工具，默认包含信息、删除、下载、局部编辑、裁剪、抠图、切图、分辨率、图片分析、识别文字、分割和复制；「显示标签」开关会为所有节点类型显示按钮文字标签并持久化。
- 「抠图」在 Web Worker 中运行约 42MB 的背景移除模型，并在右侧新增一个透明底 PNG 节点、建立连线并选中；模型可在 设置 → 本地模型 下载，也可首次使用时自动下载并显示进度，全程界面保持可操作。
- 「切图」打开点选分割弹窗（左键点前景、Alt 或右键点背景，支持撤销上一点与清空），在本地运行 MobileSAM（ONNX，首次按需下载约 45MB 并缓存），显示所选蒙版的 IoU 与叠加预览，并在右侧生成透明底结果节点；编码器每张图只运行一次，后续加点仍保持流畅。
- 「分辨率」提供三个页签：算法放大（1K/2K/4K 预设、算法选择与输出预览，源图最长边达到目标时禁用确认）、算法缩小（1024/768/512 预设加 64-4096px 自定义目标，仅当目标小于源图最长边时可确认）和 AI 提升（2x/4x 倍数与可编辑提示词，以该图片为唯一参考图调用已配置的图片模型）。本地结果连线显示放大结果、AI 结果显示 AI 提升结果，两种情况都会选中新节点。
- 「图片分析」弹窗显示图片主色板、EXIF 键值列表（没有时给出空状态提示）和感知哈希；选择比例（1:1 / 4:3 / 3:4 / 16:9 / 9:16）并确认后，会在右侧用智能裁剪生成新的图片节点。
- 「识别文字」把图片发给已配置的文本模型，并在右侧创建并选中一个文本节点；未配置文本模型或 Key 时会打开设置，未识别到文字会提示错误且不建节点，请求失败会显示错误原因而不会卡在加载提示。
- 双击图片打开大图预览，底部提供下载按钮；悬停工具栏同样提供下载。
- 局部编辑要求已涂抹区域并填写修改要求；确认后会在原图下方生成「遮罩标注」图片节点（原图叠加半透明蓝色涂抹区域），并在右侧生成同时接收两者连线的结果节点；请求按两张普通参考图发送、提示词按索引说明，不携带 `mask` API 参数。画笔圆环跟随鼠标，缩放时涂抹保持流畅。

## 资源节点与本地文件夹

- 工具栏与创建菜单提供一个「资源」节点，每个节点只绑定一个本地文件夹：绑定的文件夹作为根目录，子文件夹带文件夹图标列在文件上方（文件仍是纯文件名的纵向列表，不显示缩略图或网格，上限 200 个文件并给出状态提示），把文件拖到画布上即创建对应节点，点击则在画布中心插入，重新打开画布或切换画布都会恢复该节点的绑定与文件列表。
- 「资源」节点表头下方新增一行紧凑导航：返回按钮加面包屑（根目录名与各级子目录）。点击文件夹行进入该子文件夹，点击面包屑可跳回任意上级，返回按钮回上一级并在根目录禁用，因此无法导航到绑定文件夹之外；当前路径只保存在内存中、不做持久化，重新打开画布或切换画布后回到根目录。
- 每个「资源」节点各自绑定并记住自己的文件夹（按节点单独保存在 IndexedDB，不写进节点 metadata 或画布项目数据）；新建的资源节点默认不绑定、列表为空，不会继承其他节点或上次会话的文件夹。
- 把图片节点拖到「资源」节点上松手会动画回弹到原位，把图片写入该节点绑定的文件夹，显示「保存中 → 成功/失败」并刷新文件列表；拖动时该节点会高亮为拖放目标。节点不再有独立的输出文件夹，也不会自动写入上游结果。
- 「资源」节点左上角改为来源下拉框（本地文件夹 / 插件缓存），不再重复显示节点名称；选择会写入节点 metadata，重新打开画布或切换画布后保留，两种来源各自保留自己的表头操作与列表。
- 安装并连接 OpenCanvas 浏览器插件后，切到「插件缓存」会列出插件缓存里的图片文件名（与文件夹列表一样最多 200 条并显示数量），每行可拖到画布或点击插入为普通图片节点；未安装插件时显示「未检测到插件」与安装提示且不报错，本地文件夹行为保持不变。
- 「资源」节点中悬停文件行会显示预览按钮，点击后在浮层里查看该资源（图片、视频播放器、音频播放器或文本内容）；文件行本身的点击插入与拖到画布行为保持不变。列表仍然只显示文件名，只有正在预览的那一行会被读取，不会预加载其他文件，关闭浮层后即释放预览。

## 画布 MCP 与 Agent 权限

- 画布浏览器桥接与 HTTP MCP 端点融合进前端应用，与画布共用同一端口。执行 `cd web; npm run dev` 后，`http://127.0.0.1:3000/health` 与 `/config` 正常返回，`GET /` 与 `/canvas/<id>` 仍返回前端页面，MCP 客户端连接 `http://127.0.0.1:3000/mcp` 应能看到 30 个画布工具。画布在同源下自动连接，无需 token 或配置文件。
- `canvas_create_node`、`canvas_apply_ops` 的 `add_node` 与 `delete_node` 支持全部内置节点类型（文本、提示词、音乐提示词、语音提示词、视频提示词、图片、视频、音频、生成配置、图片生成、语音生成、音乐生成、视频生成、智能画布、资源、录音、图片修饰）；未知类型会被拒绝，且不存在 `canvas_group_nodes` / `canvas_ungroup_nodes`。
- 节点工具：MCP 客户端可设置锁定/隐藏（`canvas_set_node_flags`）、批量重命名（`canvas_bulk_rename`，单节点用原名，多节点编号为「标题 1」「标题 2」…）、对齐/等距分布（`canvas_align_nodes`，分布需 3 个以上节点）和复制节点（`canvas_duplicate_node`，默认偏移 40/40 并选中副本）。未知 id 会被忽略而不会破坏画布。
- 设置 → Agent 页为每类画布操作提供一个开关（共 10 类，默认全部允许）；关闭某类后该操作会被拦截、弹出提示并计入被拦截数。
- 每次 Agent 操作批次都会记入 Agent 审计日志，包含时间、操作数、被拦截数与操作摘要；日志最多保留最近 100 条，「清空」清空列表，「恢复默认」重新开启全部权限。回放一条记录会重新执行同样的操作，并新增一条标记为「已回放」的记录。

## 外观与响应式布局

- 应用与画布外壳（导航、画布顶栏、底部工具栏、悬停/选择浮层、侧栏、小地图）使用带细边框的半透明毛玻璃表面；画布节点、弹层、工具栏和资产卡片不使用投影，状态只用边框和轮廓环表达。
- 应用与画布共用一套暖色 token，画布库、设置、下拉与输入控件在深浅色下都与画布同一套配色，切换主题会整体更新。
- 所有界面文字使用圆体字体栈（英文 Baloo 2、简体中文资源圆体），支持真实的 400/700 字重；字体 CDN 不可用时回退到系统圆体。
- 节点设置、画板、图层与文字样式弹层共用同一进入动画，系统开启「减少动态效果」时会自动关闭。
- 在 375 / 768 / 1280 / 1440 宽度下，画布库、设置页和画布页都不出现横向滚动或控件重叠；手机端画布侧栏覆盖在顶栏下方并带收起按钮，底部工具栏横向滚动且不与缩放控件重叠，固定宽度弹窗不超出屏幕。设置中的语言切换立即生效并在刷新后保留。
- 图像工作台与音频合成器统一了外壳尺度：两者的选项栏都是两行固定高度（走带/文档行 + 带下边框的菜单与工具选项行），分隔线与 24px 控件一致；左侧工具列图标尺寸、间距一致，停靠区页签条高度一致，面板行使用同一套标签列宽与行距，两个工作台读起来像同一个应用。停靠区分隔条改为可见细线并加宽拖拽区；窄屏下停靠区自己收窄（1280 为 240px、1024 以下 208px，底部停靠区 184/160）而不是挤压中间文档或时间轴。图像工作台底部取色面板改为横向布局（取色区 / 数值区 / 色板），短片面板里不再裁切也不再强制滚动；文字面板拥挤的行按控件组换行，不会再把开关裁掉。音频合成器在 1024 以下把走带收成「返回 / 播放暂停 / 位置读数 + 面板开关 + …」，速度、拍号、循环、节拍器、缩放与「存为音频节点」仍都在该菜单里可达；右侧面板在该宽度仍是浮层，编曲视图开关上方不再多画一条分隔线。
