# 功能介绍

本文档记录当前项目已经实现的主要功能。

## 画布项目

- 支持创建、重命名、移动和删除画布，并按库（分组）组织画布；画布库页面可新建、重命名和删除库。
- 左侧面板提供可搜索的画布快速切换，可拖拽调整画布顺序。
- 画布项目、视图、背景、节点、连线和生成记录保存在浏览器本地。
- 支持把单个或多个画布导出为一个 zip（包内 `projects.json` 清单记录格式版本与每个资源文件），也支持导入该 zip 新建画布（不覆盖已有画布）。

## 画布编辑

- 支持拖动画布、滚轮与滑杆缩放、重置视图，以及开关小地图。
- 支持框选、Shift / Cmd 追加选择，以及复制、粘贴、复制节点和删除节点。
- 支持撤销和重做节点、连线、视口与背景变化。
- 支持点阵、网格线、空白三种背景，以及浅色 / 深色主题。
- 支持顶部与左侧坐标标尺，随平移和缩放实时更新。
- 支持 16px 网格吸附；与其他节点对齐的参考线优先于网格。
- 支持对齐（左 / 居中 / 右 / 上 / 垂直居中 / 下）与等距分布（水平 / 垂直，需选中 3 个以上节点）。
- 支持节点锁定与隐藏，可在「节点列表」或节点「层级」弹层中管理，并对多个节点批量重命名。

## 节点

- 内容节点：文本、图片、视频、音频。
- 提示词节点：提示词、音乐提示词、语音提示词。
- 生成节点：生成配置、图片生成、语音生成、音乐生成。
- 画板节点：智能画布。
- 工具节点：资源、录音、图片修饰。

底部工具栏把节点创建归入「提示词 / 生成器 / 输入输出 / 修饰」几个菜单，并单独提供「智能画布」按钮。提示词节点只保存提示词文本并连到生成节点；音乐提示词和语音提示词带标签快捷输入并连到对应生成节点，语音提示词还可以选择参考节点。

## AI 生成

- 由浏览器前端携带用户提供的 API Key 直接请求 OpenRouter（`https://openrouter.ai/api/v1`），不经过项目服务器。
- 支持文本、图片（文生图与参考图编辑）、视频、语音和音乐生成。
- 图片生成支持数量、分辨率（`1K` / `2K` / `4K` / 自动）、宽高比、质量与透明背景，默认保留图片原始比例，并记录提示词、模型、尺寸、质量、数量和参考图以便重试。
- 视频生成支持 OpenAI 风格视频接口、首尾帧或通用参考模式、4–30 秒时长，以及刷新页面后续跑远端任务。
- 语音和音乐生成使用预设的 OpenRouter 模型，输出 MP3。
- 生成结果直接排布在画布上，不再自动连回生成节点。

## 图片工具

- 支持裁剪、分割并生成新的图片节点。
- 支持局部蒙版编辑，可选择导出到画布或立刻生成。
- 支持分辨率调整：本地放大 / 缩小预设，或通过已配置的图片模型进行 AI 增强。
- 支持本地模型背景移除（首次使用时按需下载）。
- 支持图片分析：主色板、EXIF、感知哈希，以及按比例智能裁剪。
- 支持识别文字（OCR）：调用已配置的文本模型并把结果生成文本节点。
- 支持本地 MobileSAM 点选分割（约 45MB，浏览器缓存），生成透明底图片节点。
- 支持截取视频节点的首帧、尾帧或当前帧为新的图片节点。

## 智能画布

- 固定比例画板，合成分辨率可选 `1K` / `2K` / `4K`。
- 背景可选透明、白色、黑色或自定义颜色，并可调整不透明度。
- 把图片节点拖到画板上即完成置入：图片仍可编辑、随画板移动，画板始终位于图片下方。
- 图层面板：调整前后顺序、显示 / 隐藏，并为每个图层选择混合模式（16 种 Photoshop 等效模式）和不透明度。
- 支持在画板上添加文字标注。
- 一键排版提供网格、单行、单列、主图四种模板。
- 支持嵌套画板：嵌套画板递归渲染、递归合成。
- 支持预览合成（把画板压平成一张图片）与「存为图片节点」。
- 画板连到生成节点时，会把合成图作为参考图输入。

## 素材

- 「资源」节点可绑定一个本地文件夹（File System Access API），最多列出 200 个图片、视频、音频与文本文件，点击或拖拽即可插入画布。
- 把图片拖到「资源」节点上会保存进已绑定的文件夹。

## 录音与图片修饰

- 录音节点使用浏览器 `MediaRecorder` 采集麦克风音频，停止后在旁边生成一个音频节点。
- 图片修饰节点支持滤镜参数、色调参数（黑场、白场、伽马、曝光、高光、阴影）以及可编辑的色调曲线，并把结果烘焙成新的图片节点；把图片拖到修饰节点上可直接烘焙。

## 本地画布 MCP

- 前端应用自身在与画布相同的端口上暴露 Streamable HTTP MCP 端点 `/mcp`，不需要单独启动进程。
- 可读取当前画布、选区、节点、连线与生成状态，并应用结构化操作。
- 可创建和编辑全部内置节点类型、连接节点、触发生成、对智能画板一键排版，以及把图片置入或移出画板。
- 设置中的「Agent」页签提供每种操作的权限开关，并保留可回放的审计日志。
- 不再有内置对话助手：外部 MCP 客户端通过无界面桥接驱动画布。

## 节点插件系统

- 支持通过 URL 动态安装、启用、更新和卸载远程节点插件。
- 插件面板可从官方插件注册表读取插件列表。
- 提供 TypeScript 插件开发 SDK，可自行开发带面板、资源输入和可选 AI 生成能力的画布节点插件。
- 内置 Markdown、SVG、HTML、3D 全景、便利贴等示例插件。

## 配置

- 在设置中填入 OpenRouter 的 API Key；Key 保存在浏览器本地，由前端直接请求 OpenRouter。
- 设置页签包括：接口（API Key）、外观（语言、主题、默认画布背景）、生成（默认画布生图数量）、本地模型、本地存储、费用、Agent 和关于。
- 「费用」页签在 OpenRouter 返回用量信息时汇总已记录的生成费用。

## 当前限制

- 画布项目、文本创作器的作品和生成记录都保存在浏览器本地，不提供内置云同步。
- API Key 保存在浏览器本地，并由浏览器直接请求 OpenRouter；只适合个人或可信设备使用。
- 服务商固定为 OpenRouter；当前版本不提供自定义 OpenAI 兼容 Base URL 和自定义调用脚本。
- 画布更适合桌面端使用，移动端触控体验还未系统完善。

更多细节见[本地画布 MCP 连接画布原理](/zh-CN/docs/development/local-canvas-mcp)和[画布节点操作手册](/zh-CN/docs/canvas/canvas-node-manual)。
